# ADR-0000: 采用 ADR 记录架构决策

## 状态

Accepted

## 背景

随着项目增长，需要在代码之外记录关键的架构、技术与流程决策，以便后续维护者理解"为什么这样设计"。

## 决策

采用轻量级 **Architecture Decision Records (ADR)** 格式记录所有非显而易见的架构与流程决策。

## 格式

- 文件：`docs/adr/000N-kebab-title.md`
- 内容：标题、状态、背景、决策、后果、相关 ADR。

## 后果

- 新决策必须写入 ADR。
- 已接受的 ADR 变更需通过新的 ADR 覆盖，而不是直接修改原文。
- 项目初始化阶段已建立 `docs/adr/` 目录，后续按编号递增。
